How It Works
Upload any CSV and the app handles everything
1
Upload any CSV dataset
Drop any CSV file — no configuration needed. The app detects your ID column and recommends possible target columns. You confirm the target and which value means churn before anything is trained.
2
Run the ML pipeline
Click Run Pipeline (enabled after you confirm the target): load into MySQL, split train/test, SMOTE on the training split only, train, evaluate on held-out data, generate SHAP explanations.
3
Explore predictions
Navigate to Overview for KPIs, Customer Risk Table for all predictions, Model Evaluation for ROC curves, and SHAP Explainability.
