How It Works
Upload any CSV and the app handles everything
1
Upload any CSV dataset
Drop any CSV file — no configuration needed. The app automatically detects your ID column, binary target column, categorical features, and numerical features. Works with any domain.
2
Run the ML pipeline
Click Run Pipeline to trigger all 6 automated stages: load into MySQL, feature engineering, SMOTE class balancing, train 4 models (Logistic Regression, Random Forest, XGBoost, MLP), evaluate all models, generate SHAP explanations.
3
Explore predictions
Navigate to Overview for KPIs, Customer Risk Table for all predictions, Model Evaluation for ROC and confusion matrix charts, and SHAP Explainability to understand what drives each prediction.
